# New Prototype

Route to `project-lifecycle` with profile `experiment/prototype`.

Collect only decisions that affect the learning objective, target users, hypothesis, prototype fidelity, technical scope, evaluation method, time/resource budget, expiry condition, data handling, and promotion criteria.

Do not silently turn a prototype into production architecture. Record what is intentionally temporary, what evidence would justify promotion, and what should be discarded.
