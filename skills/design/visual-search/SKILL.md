# Visual Search

Use real references when they improve a design decision. Do not replace design reasoning with search results.

## Search workflow
1. Read the project design brief and constraints.
2. Generate search dimensions: industry, audience, product type, mood, layout, interaction, device, content type, and visual subject.
3. Search reference galleries and asset libraries separately.
4. Prefer source pages that expose the original creator and license/usage information.
5. Capture the exact URL and why the item is relevant.
6. For screenshots, record them as reference evidence unless reuse rights are clear.
7. For assets, verify the license and any restrictions before downloading.

## Tool neutrality
The skill may use a web/image-search capability, an approved asset provider, or another project-authorized retrieval tool. It must not assume a specific search provider or silently install a new tool.

## Selection rubric
Score each candidate on:
- relevance to the brief
- visual quality
- originality
- usability/accessibility implications
- implementation feasibility
- licensing/provenance confidence
- risk of making the product look derivative or generic

## Output
Produce a shortlist with source, URL, type, useful attributes, reuse status, and recommended use: inspiration / direct licensed asset / needs permission / reject.
