# Asset Direction

Assets should support the message, not fill empty boxes.

## Process
1. List the visual job each asset must perform.
2. Prefer owned, commissioned, properly licensed, or public-domain assets when appropriate.
3. Record source and provenance for external assets.
4. Define crop, aspect ratio, focal point, responsive variants, loading strategy, alt text, and fallback.
5. Reject generic stock imagery when it undermines authenticity.

## Identity and truthfulness
Never invent a real organization's logo, testimonial image, facility, customer, product photo, certification mark, or factual screenshot merely to fill visual space. Use clearly labeled placeholders when necessary.

## Generated imagery
Treat generated imagery as optional art direction, not factual evidence. Where authenticity matters, do not create realistic people, facilities, products, documents, interfaces, or other representations that could reasonably be mistaken for genuine source material.

## Web sourcing
When browsing visual references, save links and describe what is being learned from them. Do not copy proprietary images into a project merely because an example looks useful.

## Verification
Check dimensions, layout shift, loading cost, alt behavior, responsive crops, dark/light contexts, and visual consistency.
