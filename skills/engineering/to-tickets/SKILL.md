# To Tickets

Prefer vertical slices that deliver a narrow behavior end to end over horizontal layer tickets. For each item capture outcome, acceptance criteria, dependencies, validation evidence, AFK-safe vs HITL-required, and scope boundaries.

Present the proposed ordering before publishing tracker issues. Use project-configured tracker vocabulary. Never place secrets or private credentials in issue content.

The top unblocked slice should be implementable without reopening settled product decisions.
