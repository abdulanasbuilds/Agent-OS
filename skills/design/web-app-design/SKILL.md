# /web-app-design

Load `design-router` with web-application context.

Start from user workflows and information architecture, not decorative landing-page patterns. Define navigation, hierarchy, states, forms, tables/data views, feedback, empty/loading/error states, responsive behavior, and component language.

Use references selectively and verify that imported component patterns fit the product instead of reproducing library-demo aesthetics.
