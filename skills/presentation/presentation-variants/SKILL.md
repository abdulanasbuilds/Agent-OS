# Presentation Variants

Use a variant lab when the user has not settled on a visual direction or explicitly asks for alternatives.

## Process
1. Freeze the same narrative/content outline for all variants.
2. Create 2-4 genuinely different visual hypotheses.
3. Vary composition, typography, imagery, density, or visual language—not only colors.
4. Render local previews and representative slide screenshots.
5. Compare using the same criteria: message clarity, audience fit, distinctiveness, readability, accessibility, implementation cost, and output fidelity.
6. Record the selected direction and promote only that variant to the primary branch/workspace.

Never mutate the main presentation while exploring multiple directions.
