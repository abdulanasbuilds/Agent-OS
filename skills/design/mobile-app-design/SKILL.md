# /mobile-app-design

Load `design-router` with mobile-application context.

Start from mobile user jobs and task flows. Consider navigation, touch targets, gestures, keyboard behavior, safe areas, device sizes, orientation, offline/error states, permissions, accessibility, motion, performance, and platform conventions.

Do not simply shrink a desktop layout. Design the mobile information hierarchy and interactions intentionally.
