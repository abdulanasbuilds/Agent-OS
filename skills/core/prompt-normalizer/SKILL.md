# Prompt Normalizer

Treat raw user language as intent. Before execution, derive:

- objective
- desired outcome
- known requirements
- constraints
- non-goals
- current context
- missing information
- acceptance criteria
- requested authority level

Preserve the user's meaning and level of ambition. Do not silently add features.

Ask only questions whose answers would materially change the plan or result. When enough context exists, continue without unnecessary interrogation.

For large requests, create a durable objective/spec artifact and route the work through the autonomous loop.

Keep the working prompt compact. Avoid repeating context already present in project artifacts.
