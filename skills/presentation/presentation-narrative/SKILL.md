# Presentation Narrative

Lock the argument before decoration.

## Process
1. State the audience and desired outcome.
2. Reduce the material to 1-3 core messages.
3. Choose an arc appropriate to the purpose: problem/solution, before/after, story, argument/evidence, process, teaching progression, decision memo, or another justified structure.
4. Give every slide one primary job.
5. Sequence evidence so each slide earns the next.
6. Add transitions only where they improve comprehension.
7. Design the close around the desired decision, action, takeaway, or next step.

## Evidence
Separate sourced facts, calculations, assumptions, examples, and recommendations. Do not invent metrics or citations.

## Compression
Prefer splitting an overloaded slide over shrinking text. Use appendices for detail that matters but should not compete with the main narrative.

## Output
Produce a slide map with slide number, purpose, headline/message, supporting evidence, visual idea, and notes requirement before final slide production.
