# Ask Agent

Use when the user describes a situation rather than naming a skill.

Inspect the repository first. Identify the phase, uncertainty, urgency, and whether the work is one-context, multi-session, exploratory, or routine. Recommend the smallest useful skill or short sequence. State human checkpoints for product, architecture, design, security, licensing, or deployment decisions.

Do not activate broad skill groups merely because they exist. Routing never grants tool permission.
