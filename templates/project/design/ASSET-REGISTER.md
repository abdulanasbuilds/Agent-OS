# Asset Register

Every nontrivial visual asset used by the project should have provenance.

| Asset | Type | Source | License/rights | Intended use | Alt text | Optimization | Status |
|---|---|---|---|---|---|---|---|
| | | | | | | | |

## Rules
- Prefer original, user-supplied, licensed, or public-domain assets.
- Record the actual source and license instead of assuming a gallery listing grants reuse rights.
- Do not commit secrets, private client assets, or unapproved third-party files.
- Provide responsive crops and meaningful alternative text where applicable.
