# Presentation QA

Never sign off a deck because it looks good at a glance.

## Per-slide review
Check:
- one primary message
- clear headline
- readable at presentation distance
- visual hierarchy and reading path
- no overflow, clipping, or accidental overlap
- correct source/citation where needed
- consistent spacing and type roles
- appropriate image quality
- logical reading order

## Deck-level review
Check narrative progression, pacing, variation of layouts, repeated components, visual rhythm, section transitions, appendix separation, speaker-note coverage, and final action/next step.

## Output review
For PPTX verify editability and layout. For PDF verify export fidelity. For HTML verify viewport fit, controls, keyboard access, and reduced-motion behavior where applicable.

## Failure policy
Every failed check must either be fixed or explicitly documented as an accepted limitation before delivery.
