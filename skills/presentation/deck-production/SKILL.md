# Deck Production

Select output from the user's needs, not tool fashion.

## Modes
- PPTX: prioritize editability, native structure, reusable masters/components, and reading order.
- PDF: prioritize export fidelity and print/screen readability.
- HTML: prioritize responsive/viewport behavior, interaction, keyboard access, and reduced-motion handling.
- Other formats: identify the actual consumer and verify the target tooling before committing.

## Source-first rule
Maintain a structured outline/source representation before generating the final artifact when practical. Fix source data or generation logic rather than manually patching only the final binary.

## Tool selection
Use an existing project stack when sufficient. Add a presentation library only when the project needs it. Prefer maintained, auditable tooling and check current documentation before using version-sensitive APIs.

## Verification
Render or open representative slides/pages in the target output. Inspect layout, fonts, imagery, charts, links, notes where applicable, and output integrity before delivery.
