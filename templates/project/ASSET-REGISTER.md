# Asset Register

Every external asset shipped by this project should have a record.

| ID | Local path | Type | Source URL | Creator | License/terms | Date checked | Reuse class | Attribution | Notes |
|---|---|---|---|---|---|---|---|---|---|
| A-001 | | | | | | | | | |

## Reuse classes

- `project-owned`
- `licensed`
- `open-license`
- `reference-only`
- `needs-permission`
- `reject`

## Rules

1. Reference screenshots do not automatically become shippable assets.
2. Verify individual asset terms, not just the marketplace homepage.
3. Record the exact source and license URL.
4. Keep proof of license where practical for commercial work.
5. Never commit credentials, private customer media, or unrelated personal data.
6. Remove/relicense assets when terms change or the project loses the right to use them.
