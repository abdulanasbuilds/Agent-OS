# Reference Discovery

Search for references to answer a design question, not to collect pretty screenshots.

## Search categories
- visual direction
- information architecture
- typography
- components
- interaction patterns
- motion
- imagery/art direction
- accessibility examples

## Evaluation
For each reference, record why it is useful, what is transferable, what is product-specific, and whether assets/code may be reused.

## Sources
Prefer first-party component/documentation sources for implementation details. Use curated galleries such as Awwwards, Behance, Dribbble, Figma Community, Recent Design, and Relume Community for visual discovery and comparative research.

## Rights
Do not assume visual availability means reuse permission. Store links and analysis when rights are unclear. Recreate principles rather than copying protected assets or distinctive branded work.

## Output
Return a small, ranked reference set with design lessons instead of a large undigested gallery dump.
