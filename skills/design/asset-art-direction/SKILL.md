# Asset Art Direction

Choose assets as part of the design system, not as filler.

## Process
1. Identify the narrative job of each asset.
2. Define subject, crop, aspect ratio, tone, lighting, palette, density, and placement.
3. Prefer original, licensed, public-domain, or user-supplied assets.
4. Record source, license, attribution requirements, and intended reuse.
5. Provide responsive crops and meaningful alt text where applicable.
6. Optimize file size and loading behavior.

## Agent behavior
If the user has not provided assets, do not invent a random stock-photo style. Propose an art direction and a sourcing/generation strategy first.

## Rights
Do not download or redistribute protected gallery assets merely because a reference site displays them. Store links and analysis when rights are unclear; store files only when reuse is authorized.
