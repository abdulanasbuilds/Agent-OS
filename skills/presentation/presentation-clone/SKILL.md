# Presentation Clone

First determine whether the source is owned by the user or reuse is explicitly authorized.

## Authorized clone
Measure and reproduce, as appropriate:
- slide dimensions
- master/layout structure
- typography and spacing
- visual hierarchy
- imagery placement
- charts/diagrams
- transitions and animations when supported
- speaker notes
- content order

Prefer structured source recreation over screenshot-only imitation so the output remains editable.

## Unclear or third-party source
Do not copy proprietary assets, logos, fonts, images, source code, or distinctive protected artwork merely because it is publicly viewable. Analyze structure and principles and recreate an original implementation.

## Verification
Compare representative slides side-by-side and document any unavoidable differences caused by fonts, format, missing assets, or platform limits.
