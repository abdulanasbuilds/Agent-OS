# New SaaS

Thin alias for `project-lifecycle` with profile `product`.

Do not equate a SaaS idea with an automatic feature list. Establish buyer, user, painful workflow, value, acquisition path, willingness to pay, pricing hypothesis, unit economics assumptions, MVP boundary, and technical constraints first.
