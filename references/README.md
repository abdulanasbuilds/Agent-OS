# Agent OS Reference Library

This directory is the curated visual-reference index for Agent OS.

It is intentionally **not** a scraped asset dump.

The library helps an agent discover:
- site and app inspiration
- interaction and motion references
- component systems
- typography and fonts
- image/video sources
- UI screenshots and product patterns
- design education and UX principles

## Usage classes

`reference-only` = analyze/inspire; do not ship copied material.

`asset-source` = may provide reusable assets, but the agent must verify the individual asset's license and restrictions before downloading/shipping.

`tool/library` = software or component system that may be adopted at project level after evaluating compatibility, maintenance, accessibility, performance, license, and dependency risk.

`design-education` = principles, heuristics, and learning material.

## Core workflow

1. Read the project's design brief.
2. Search this catalog by category and tags.
3. Retrieve the source page and inspect the current item.
4. Record useful reference attributes.
5. Verify reuse rights before shipping an asset.
6. Save project-specific references in the project's `references/` or design-lab area.
7. Keep third-party source material out of the global repository unless it is explicitly licensed for redistribution.

See `DESIGN-REFERENCE-CATALOG.yml` for the source registry and `docs/DESIGN-REFERENCE-LIBRARY.md` for the operating rules.
