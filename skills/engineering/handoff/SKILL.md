# Handoff

Create a handoff when work must cross a session, harness, directory, teammate, or focused side task.

Include objective, current state, verified facts, decisions/ADRs, changed files/commits, validation results, blockers, open decisions, next action, and suggested skills. Link to existing artifacts instead of duplicating them. Redact secrets and sensitive personal data.

Prefer staying in the same context when it still contains important primary-source reasoning.
