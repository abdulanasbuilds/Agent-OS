# New API

Route to `project-lifecycle` with profile `api/backend-service`.

Collect only decisions that materially affect protocol, consumers, authentication, authorization, data model, sync/async behavior, rate limits, observability, deployment, and versioning.

Design the contract and trust boundaries before implementation. Never expose internal service credentials to clients.
