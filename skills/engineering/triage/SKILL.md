# Triage

Classify the item as bug, enhancement, task, question, or duplicate. Determine impact, urgency, evidence, affected area, missing information, and security/privacy implications.

Use a small state model such as needs-triage → needs-info → ready-for-agent → ready-for-human → done. Preserve reporter intent and never rewrite an item merely to make it look resolved.

Do not place secrets or sensitive personal information into tracker content. Triage does not grant implementation or production authority.
