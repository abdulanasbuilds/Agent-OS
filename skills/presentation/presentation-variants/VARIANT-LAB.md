# Presentation Variant Lab Contract

Use with `presentation-variants` when the deck's visual or narrative direction is genuinely unresolved.

## Required behavior

- Freeze the approved or working content outline before detailed visual comparison unless narrative itself is the decision under test.
- Keep every candidate in an isolated local workspace or branch.
- Use the same slide count range, source material, dimensions, and output requirements for visual comparisons.
- Render representative slides from every candidate using the same environment.
- Compare message clarity, audience fit, hierarchy, readability, accessibility, distinctiveness, editability, output fidelity, and production cost.
- Wait for an explicit selection when the user owns the decision.
- Promote only the selected candidate to the primary deck.

## Do not

- overwrite the primary deck while exploring;
- create variants that differ only by color;
- copy third-party proprietary templates/assets without a reuse basis;
- treat a beautiful visual direction as automatically effective communication.
