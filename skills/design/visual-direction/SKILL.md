# Visual Direction

Treat visual direction as a product decision, not decoration.

## Process
1. Read the design brief and project context.
2. Identify visual territory appropriate to the audience and category.
3. Identify obvious category conventions that matter for trust.
4. Identify conventions worth breaking where differentiation helps.
5. Define composition, density, surface treatment, color behavior, typography personality, imagery style, icon style, and interaction character.
6. Explain why each choice supports the product.

## Anti-slop check
Before implementation, explicitly reject any default aesthetic that is present only because it is trendy or commonly generated by AI.

Ask:
- Would this still fit if the product name and logo were removed?
- Is the interface recognizable from the composition rather than a gradient or font?
- Are decorative effects doing useful work?
- Is the design dependent on generic stock imagery?

## Output
Create a concise visual-direction sheet with:
- visual thesis
- references and what is borrowed as inspiration only
- visual vocabulary
- things deliberately avoided
- typography role
- color role
- surface/material behavior
- imagery direction
- component character
- motion character
- responsive character
