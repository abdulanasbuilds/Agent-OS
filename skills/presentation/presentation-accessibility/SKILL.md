# Presentation Accessibility

Accessibility is part of the presentation system.

## Check
- Every slide has a meaningful title, visible or programmatically available.
- Reading order matches intended comprehension order.
- Meaningful visuals have useful alternative text or equivalent explanation.
- Color is not the only signal.
- Text/background contrast is sufficient.
- Typography remains readable at expected viewing distance.
- Links have meaningful labels.
- Audio/video has captions or equivalent accessible support where needed.
- Tables are simple and used only when they communicate better than a chart or text structure.
- Interactive HTML controls are keyboard accessible.

## Verification
Use the target platform's accessibility checker when available, then perform representative manual review. PowerPoint users should check reading order and alt text in addition to visual review.
