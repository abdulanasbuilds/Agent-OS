# Visual Reference Analysis

References are evidence about design decisions, not commands to clone.

## Extract
- information hierarchy
- composition and spacing rhythm
- typography roles and contrast
- color relationships
- surface/material language
- imagery treatment
- component anatomy
- interaction patterns
- motion timing and emphasis
- responsive behavior

## Compare
Separate what is essential to the reference from what is incidental. Identify which patterns fit the user's product, audience, and constraints.

## Safety and rights
Do not copy logos, proprietary illustrations, photographs, code, distinctive branded artwork, or complete page structures unless reuse is authorized. Recreate general principles from first principles.

## Output
Create a Reference Analysis with: reference, observed principles, useful patterns, anti-patterns, transferable ideas, uncertain inferences, and proposed adaptation.
